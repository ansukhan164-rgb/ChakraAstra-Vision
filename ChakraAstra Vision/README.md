# Itachi Sharingan Hand UI (Flask)

## Run
```bash
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000/`.

## Gestures
- Tiger: two hands up close together
- One-handed: index + middle up
- Genjutsu: five fingers up
- Mangekyō Awakened: ten fingers up (both hands open)
- Techno Hacker Pulse: click button or press `5`
