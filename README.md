# 🔮 ChakraAstra-Vision

An advanced AI-powered vision platform that combines Computer Vision, Machine Learning, and Intelligent Automation to analyze, detect, and understand visual data in real time.

## 🚀 Overview

ChakraAstra-Vision is designed to bring powerful visual intelligence to modern applications. The platform leverages cutting-edge AI models to process images and video streams, detect objects, recognize patterns, and generate actionable insights.

Whether you're building smart surveillance systems, automated monitoring solutions, AI assistants, or intelligent analytics platforms, ChakraAstra-Vision provides a scalable foundation for visual AI.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/ansukhan164-rgb/ChakraAstra-Vision.git
cd ChakraAstra-Vision
```

### Install Backend Dependencies

```bash
pip install -r requirements.txt
```

### Install Frontend Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

or

```bash
python app.py
```
